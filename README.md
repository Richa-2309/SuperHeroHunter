# SuperHeroHunter 🦸

A simple **SuperHero Hunter** web project created to practice and strengthen my **HTML and CSS** skills.

## 🚀 Features

* Search for superheroes
* Display superhero information
* Simple and responsive UI
* Hero cards with images and details
* Clean HTML structure and CSS styling

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🎯 Purpose

This project is created for practicing:

* HTML structure and semantic tags
* CSS layouts
* Flexbox
* Responsive design
* Cards and navigation bars
* Styling and positioning elements
